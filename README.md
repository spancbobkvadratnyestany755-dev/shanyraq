# Shanyraq

Поиск жилья и коммерческих помещений в Алматы. Ранняя версия сайта на HTML, CSS и JavaScript.

## Возможности

- Вход и повторная авторизация через Google (Supabase Auth).
- Создание, редактирование и снятие собственных объявлений с публикации.
- Хранение объявлений и фотографий в Supabase с правилами доступа RLS.
- Карта MapLibre и организации OpenStreetMap в радиусе 750 метров.
- Поиск и анализ окружения по правилам. Языковая модель не подключена.

## Локальный запуск

Нужен Node.js 22 или новее:

```sh
node serve.mjs
```

Открыть http://127.0.0.1:3000/ . Для Google-входа этот адрес должен быть разрешён в Supabase и Google OAuth.

Подробная настройка: [SETUP.md](SETUP.md). `schema.sql` выполняется один раз при создании новой базы, а не при каждом запуске.

## Настройки

`config.js` содержит только публичный URL и Publishable key Supabase. Пароли, Google Client Secret и ключи service_role не должны попадать в репозиторий. Доступ к данным определяется политиками базы, а не скрытностью публичного ключа.

## Текущее состояние

Таблица и Google-провайдер были настроены; полный вход и разграничение доступа между двумя аккаунтами требуют проверки. Это исходный код, а не опубликованный сайт. Не следует считать проект прошедшим аудит безопасности. Анализ окружения не прогнозирует проходимость, спрос или прибыль.
