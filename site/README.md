# Shanyraq: презентация с ИИ

35 демонстрационных анкет с разными характеристиками и оценками, 12 сгенерированных изображений, карта с вымышленными заведениями в радиусе 750 м.

## Запуск с OpenAI

Нужен Node.js 22 или новее. В корне репозитория откройте START.cmd на Windows, введите новый ключ в скрытое поле и откройте http://127.0.0.1:3100. Ключ хранится только в памяти; не добавляйте его в файлы или GitHub.

На других системах установите переменную окружения OPENAI_API_KEY и выполните `node server.mjs` из корня. Модель по умолчанию gpt-4.1-mini, её можно изменить переменной OPENAI_MODEL. Запросы платные. Предел 50 запросов за запуск не является лимитом в долларах.

Сервер принимает подключения только с ноутбука. GitHub хранит исходники и сам не запускает этот сервер. Статическая презентация: https://shanyraq-pitch.asel-yesseykyzy.chatgpt.site/ — там пока помощник по правилам.

ИИ получает каталог, последние четыре пары сообщений, выбранную анкету и демоточки. Он отвечает свободным текстом и может открыть карточку или выделить категорию точек. Демоокружение не подтверждает реальные спрос, проходимость и прибыль.

Проверка кода из корня: `node --test server.test.mjs` и `node ui.test.cjs`. Тесты используют подменённый ответ API, деньги не расходуют. Настоящий ответ требует действующего ключа с доступом к модели и балансом.
